description: บันทึก/โหลด session handoff — save (ค่าเริ่มต้น) | load <ไฟล์> | list
---

ผู้ใช้เรียกคำสั่ง handoff ด้วยอาร์กิวเมนต์: `$ARGUMENTS`

ให้โหลด skill `handoff` (ผ่านเครื่องมือ `skill`) แล้วทำตามขั้นตอนในนั้น โดยตีความ action จาก `$1`:

- ว่าง หรือ `save` → ทำขั้นตอน **save** (สร้างไฟล์ `handoff_{unique}.md` ใน `.opencode/handoff/`)
- `load` → ทำขั้นตอน **load** โดยใช้ชื่อไฟล์จาก `$2` (ถ้าไม่มีให้ถามผู้ใช้ว่าจะโหลดไฟล์ไหน)
- `list` → ทำขั้นตอน **list**

จากนั้นตอบผู้ใช้สั้นๆ เป็นภาษาไทยตามรูปแบบที่ skill กำหนด
